About Glasto Quick Copy

Glasto Quick Copy is an independent, free project. It's made by a product manager, not a professional developer, who got fed up scrolling the group chat for six registration numbers every Glastonbury ticket day.

What we do

  • A free tool that puts your group's registration numbers and postcodes on one page, so you can copy each one with a tap.
  • Guides that explain registration, the ticket queue, deposits, balances and resale in plain English.

How the guides are checked

Every guide is based on the official Glastonbury Festival and See Tickets information, which we link to at the end of each article. Each page shows when it was last checked. Rules can change from year to year, so the official sites always have the final word. If you spot something out of date, tell us and we'll fix it.

How it's built

The tool's code is open source on GitHub, built with the help of AI coding tools and tested automatically on every change. A public check compares the live tool with the published code every six hours.

How it's funded

The site shows ads from Google AdSense, which pay for the domain and keep everything free. Ads sit in a few fixed places on each page, never between the copy buttons you use on ticket day. See our privacy and cookies policy.

Not affiliated

We're not affiliated with, endorsed by or connected to Glastonbury Festival or See Tickets. "Glastonbury" is used only to describe what the guides and tool are about.
